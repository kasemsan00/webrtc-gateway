# Public WebSocket Endpoint Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add an opt-in `/ws-public` endpoint for unauthenticated public SIP per-call credentials while preserving `/ws` auth behavior.

**Architecture:** Extend gateway API config with `API_ENABLE_PUBLIC_WS`, register `/ws-public` only when enabled, and mark those connections as public-only. Public-only WebSocket messages pass through existing call/session code after a narrow guard rejects trunk, incoming, management, and legacy flows.

**Tech Stack:** Go 1.26.2, gorilla/mux, gorilla/websocket, existing gateway `internal/api`, `internal/config`, and Go tests.

- [ ] **Step 1: Add failing WebSocket auth tests**

Add tests for missing token on `/ws` still failing and missing token on `handlePublicWebSocket` succeeding.

- [ ] **Step 2: Add client mode**

Add `publicOnly bool` to `WSClient`, split `handleWebSocket` into a shared helper that accepts `publicOnly`, and create `handlePublicWebSocket`.

- [ ] **Step 3: Add message guard**

- [ ] **Step 4: Enforce call mode**

In `handleWSCall`, reject `publicOnly` calls that include `trunkId`, `trunkPublicId`, use a resolved trunk, or omit public SIP credentials.
